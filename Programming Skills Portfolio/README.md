## Project Overview

This repository contains three C++ programming challenges developed for the Programming Skills Portfolio assessment.

## Challenges

### Challenge 1 – CO2 Calculator
A program that estimates carbon dioxide emissions based on journey distance and fuel type.

### Challenge 2 – Alexa, Tell Me a Joke
A program that reads jokes from a text file, selects one randomly and displays the setup and punchline separately.

### Challenge 3 – Book Manager
A library management program that reads book records from a text file and allows users to view, borrow and return books.
